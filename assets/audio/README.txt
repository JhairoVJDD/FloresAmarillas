Este directorio está reservado para tus archivos de audio locales opcionales:
- 'background.mp3' : Música de fondo instrumental suave.
- 'paper-open.mp3' : Efecto de sonido del desdoble y apertura de papel.

Si no colocas archivos aquí, el sistema web incluye automáticamente un sintetizador de audio procedimental con Web Audio API y melodías relajantes para que la experiencia funcione de forma 100% autónoma y sin dependencias externas.
